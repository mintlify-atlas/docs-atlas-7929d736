## Welcome to Qubership Profiler Agent

Qubership Profiler Agent is a powerful Java agent that attaches to the JVM using `-javaagent` to collect comprehensive profiling and observability data. It provides continuous tracing capabilities for monitoring application performance, detecting slow requests, capturing errors, and analyzing service calls.

## Supported Technologies

The Qubership Profiler Agent provides instrumentation for a wide range of technologies:

## Why Qubership Profiler Agent?

<AccordionGroup>
  <Accordion title="Low Overhead Continuous Profiling">
    The agent is designed to run continuously in production with minimal performance impact. It intelligently samples and captures data only when needed, focusing on slow requests and errors.
  </Accordion>
  
  <Accordion title="Comprehensive Instrumentation">
    With 30+ plugins covering popular frameworks, databases, and libraries, you get deep visibility into your application's behavior without writing custom instrumentation code.
  </Accordion>
  
  <Accordion title="Production-Ready">
    Built for enterprise environments, the agent includes robust error handling, configurable thresholds, and diagnostic tools for troubleshooting in production.
  </Accordion>
  
  <Accordion title="Open Source">
    Licensed under Apache 2.0, the agent is fully open source. You can inspect the code, contribute plugins, and customize it for your needs.
  </Accordion>
</AccordionGroup>
