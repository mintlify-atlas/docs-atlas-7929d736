This page provides detailed version compatibility information for all components supported by Qubership Profiler Agent.

## Java Runtime

### Java Virtual Machine

| JVM | Minimum Version | Maximum Version | Recommended | Notes |
|-----|----------------|-----------------|-------------|-------|
| Oracle JDK | 8 | 21 | 17 or 21 | LTS versions recommended |
| OpenJDK | 8 | 21 | 17 or 21 | LTS versions recommended |
| Eclipse Temurin | 8 | 21 | 17 or 21 | Formerly AdoptOpenJDK |
| Amazon Corretto | 8 | 21 | 17 or 21 | AWS-supported distribution |
| Azul Zulu | 8 | 21 | 17 or 21 | TCK-certified |
| GraalVM | 11 | 21 | 21 | Native image not supported |

<Warning>
  **Java 8 Support:** While Java 8 is supported, it is end-of-life. We strongly recommend upgrading to Java 17 or 21 for security and performance improvements.
</Warning>

<Info>
  **Build Requirements:** Building the agent from source requires **Java 17 or 21**. The compiled agent can then be used with Java 8+.
</Info>

## Version Compatibility Notes

<Note>
  **Semantic Versioning:** The agent follows semantic versioning. Minor version updates are backward compatible.
</Note>

<Warning>
  **Jakarta EE Migration:** When upgrading from Java EE to Jakarta EE (namespace change from `javax.*` to `jakarta.*`), ensure you use the corresponding plugins:
  - Tomcat 10+: Use `tomcat10_http`
  - Jetty 10+: Use `jetty10_http`
  - Spring 6: Use with Java 17+
</Warning>

<Info>
  **Testing:** While the agent is tested against the versions listed here, it may work with other versions. Report any compatibility issues on [GitHub](https://github.com/Netcracker/qubership-profiler-agent/issues).
</Info>

If you encounter issues with a specific version:

2. Search [existing issues](https://github.com/Netcracker/qubership-profiler-agent/issues)

   - Java version
