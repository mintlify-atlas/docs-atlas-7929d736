## Overview

The Qubership Profiler Agent provides comprehensive instrumentation for popular database drivers and clients. These plugins capture SQL queries, bind parameters, execution times, and errors to give you complete visibility into database interactions.

## DataStax Cassandra

The profiler provides separate plugins for different Cassandra driver versions to ensure compatibility.

### Cassandra 3.x Plugin

**Module**: `plugins:cassandra`

Instruments the DataStax Cassandra Java driver 3.x for:
- CQL query execution
- Prepared statements
- Batch operations
- Async query execution
- Query timing and errors

**Supported Versions**: DataStax Cassandra driver 3.x

**Configuration**: `config/minimal/50main/cassandra.xml`

### Cassandra 4.x Plugin

**Module**: `plugins:cassandra4`

Instruments the DataStax Cassandra Java driver 4.x with support for:
- Modern async API
- Reactive streams
- CQL query execution
- Prepared statements
- Query metrics

**Supported Versions**: DataStax Cassandra driver 4.x

**Configuration**: `config/minimal/50main/cassandra4.xml`

### What's Captured

- CQL query text
- Query parameters and bind values
- Execution time
- Connection information
- Error details and stack traces
- Async operation correlation

## MySQL JDBC

**Module**: `plugins:mysql`

Instruments the MySQL JDBC driver to capture:
- SQL query execution
- Prepared statement parameters
- Batch operations
- Transaction boundaries
- Connection pool activity

**Supported Versions**: MySQL Connector/J (JDBC driver)

**Configuration**: `config/minimal/50main/mysql.xml`

### Features

<AccordionGroup>
  <Accordion title="SQL Query Capture">
    Captures the full SQL query text including SELECT, INSERT, UPDATE, DELETE, and DDL statements.
  </Accordion>
  
  <Accordion title="Bind Parameter Capture">
    Records prepared statement parameters for complete query visibility, helping you debug parameter-related issues.
  </Accordion>
  
  <Accordion title="Performance Metrics">
    Tracks query execution time, allowing you to identify slow queries and optimization opportunities.
  </Accordion>
  
  <Accordion title="Error Tracking">
    Captures SQL exceptions and error details for troubleshooting database issues.
  </Accordion>
</AccordionGroup>

## ElasticSearch

**Module**: `plugins:elasticsearch`

Instruments the ElasticSearch Java client to monitor:
- Search queries
- Index operations
- Bulk operations
- Document CRUD operations
- Aggregations

**Supported Versions**: ElasticSearch Java client

**Configuration**: `config/minimal/50main/elasticsearch.xml`

### Monitored Operations

| Operation Type | Captured Data |
|----------------|---------------|
| Search | Query DSL, filters, aggregations, response time |
| Index | Document content, index name, operation time |
| Bulk | Batch size, individual operations, errors |
| Get | Document ID, index, response time |
| Delete | Document ID, index, success/failure |

## OpenSearch

**Module**: `plugins:opensearch`

Instruments the OpenSearch Java client with similar capabilities to the ElasticSearch plugin:
- Search operations

## Configuration

All database plugins are automatically enabled when the agent detects the corresponding JDBC driver or client library in your application's classpath.

### Customizing Database Instrumentation

You can customize database instrumentation by modifying the plugin configuration files:

```xml
<profiler-configuration>
  <ruleset>
    <rule>
      <class>com.mysql.jdbc.PreparedStatement</class>
      <method>execute</method>
      <method-editor>MySQLQueryHandler</method-editor>
    </rule>
  </ruleset>
</profiler-configuration>
```

### Sensitive Data Handling

<Warning>
Database plugins capture SQL queries and parameters, which may contain sensitive data. Ensure you have appropriate data retention and access control policies in place.
</Warning>

To exclude sensitive data from capture:

1. Configure the agent to filter specific queries or parameters
2. Use database-level encryption for sensitive columns
3. Review and redact captured data before long-term storage

## Performance Impact

Database plugins are designed to have minimal performance impact:

- **Low overhead**: Instrumentation code is optimized for speed
- **Selective capture**: Only slow queries or errors trigger detailed capture
- **Async processing**: Event reporting happens asynchronously
- **Sampling**: Configurable sampling rates reduce overhead

## Troubleshooting

<AccordionGroup>
  <Accordion title="Plugin Not Capturing Queries">
    - Verify the database driver is in the classpath
    - Check that the plugin configuration file is present
    - Ensure the agent is attached with the `-javaagent` flag
    - Review agent logs for instrumentation errors
  </Accordion>
  
  <Accordion title="Performance Degradation">
    - Increase capture thresholds to reduce overhead
    - Enable sampling to capture only a subset of queries
    - Check for excessive logging or event reporting
    - Review database query performance independently
  </Accordion>
  
  <Accordion title="Missing Query Parameters">
    - Verify the driver supports parameter metadata
    - Check plugin configuration for parameter capture settings
    - Some drivers may not expose bind parameters to instrumentation
  </Accordion>
</AccordionGroup>
